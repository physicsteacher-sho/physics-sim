🔒 閉管のポイント
閉口端 → 節　開口端 → 腹
基本振動：λ₁ = 4L　f₁ = V/4L
奇数倍振動のみ：f = (2m−1)×f₁
（偶数倍振動は存在しない）
🌬️ 開管のポイント
両端の開口端 → どちらも腹
基本振動：λ₁ = 2L　f₁ = V/2L
整数倍振動すべて：f = n×f₁
開口端補正 Δl → 実効長 L+2Δl

閉管の固有振動数 fₙ = (2n−1)V / 4L
（n = 1, 2, 3, … → 奇数倍のみ）
開管の固有振動数
fₙ = nV / 2L
（n = 1, 2, 3, … → 整数倍すべて）
開口端補正について 実際の腹の位置は開口端より少し外側（Δl）にずれる。
閉管の実効長：L + Δl
開管の実効長：L + 2Δl
